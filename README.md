# Close Encounters Library
- A project by Nicolas Niemi and Benjamin Kakiel
- University of Florida, COP3530, Fall 26, Kapoor

## Instructions for our project
1. Press run in the IDE
2. Enter 1 for hash tree search or 2 for quadtree search
3. Enter a latitude and longitude (this is the "viewpoint" you're searching from)
4. Enter a radius (how far from the "viewpoint" do you want to search)
5. Explore the results!
