# Close Encounters Library
- A project by Nicolas Niemi and Benjamin Kakiel
- University of Florida, COP3530, Fall 26, Kapoor

## Instructions for our project
1. Press run in the IDE
2. Enter 1 for linear search, 2 for hash grid search or 3 for quadtree search
3. Enter a latitude and longitude (this is the location you're searching from)
4. Enter a radius (how far from the location do you want to search)
5. Explore the results!
6. You can then enter another menu command to search again or exit the library using 6
